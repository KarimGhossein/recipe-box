This works for sites that allow cross-site requests — many don't, so if it fails (very common), use the fallback below: right-click the recipe page → View Page Source (or press Ctrl+U / Cmd+Option+U), select all, copy, and paste it here. Most recipe sites embed a structured recipe block for Google that we can read directly, even when a direct fetch is blocked.

For social videos, there's no reliable way for this app to watch or transcribe the clip — but creators very often put the full written recipe in the caption or a pinned comment. Paste that text (or any plain recipe text) below and we'll do our best to split it into ingredients and steps.

Select as many recipe .json files as you like at once. This reads two formats automatically: a backup file exported from this app's own Backup button, or a simple recipe format like {"title", "ingredients": [...], "instructions": [...]} (the kind produced by meal-planning/macro apps). Anything else gets skipped and listed so you know what didn't make it in.
